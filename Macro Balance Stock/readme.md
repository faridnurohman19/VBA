# Stock Balancing Tool (OMS ↔ WMS)



## Backgorund
The occurrence of a **gap** or **difference** between the **Order Management System (OMS)** and the **Warehouse Management System (WMS)** causes a **mismatch** between the stock displayed on the platform (buyer's interface) and the **actual stock** in the warehouse (WMS).  

Therefore, a **stock balancing process** is required using the formula:  
**WMS Stock - OMS Stock**  

This tool was created to **simplify** the user's reconciliation process between **OMS stock levels** and **WMS inventory**, ensuring **real-time consistency** and reducing **stock mismatches**.

## Explanation

| **Folder/File**         | **Description**                                                                 |
|-------------------------|---------------------------------------------------------------------------------|
| **targetfolder**       | The source files (raw data) for **OMS data** and **WMS data** will be placed here. |
| **Result/Demo Result**  | The output (reconciliation result) will be generated here after running the macro. |
| **demo_balancestock.xlsm** | The macro file used to execute the **stock balancing process**.                 |



## **Steps to Execute**
1. **Download Source Files**  
   - OMS Data: Download in `.csv` format.  
   - WMS Data: Download in `.xlsx` format.  

2. **Save Files**  
   - Place both files in the **`targetfolder`** directory.  

3. **Access Macro File**  
   - Open the **`demo_balancestock.xlsm`** folder.  

4. **Run Macro**  
   - Execute the process by clicking the **Run** button.  

5. **Confirmation**  
   - Click **OK** to complete the operation.
