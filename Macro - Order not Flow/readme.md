# Order not Flow Checking Tool



## Backgorund

There are issues where **orders from the Order Management System (OMS)** fail to flow into the **Warehouse Management System (WMS)** due to **unstable system connections**. This can cause **delays** and **missed orders** in warehouse operations. To solve this, a **macro tool** was created to help check **daily** whether orders have successfully flowed from OMS to WMS. This tool makes the checking process **faster**, **easier**, and more **accurate**.

## Explanation

| **Folder/File**         | **Description**                                                                 |
|-------------------------|---------------------------------------------------------------------------------|
| **targetfolder**       | The source files (raw data) for **OMS data** and **WMS data** will be placed here. |
| **order-not-flow-demo.xlsm** | The macro file used to execute the **order not flow check**.                 |



## **Steps to Execute**
1. **Download Source Files & Save As**  
   - OMS Data: Download in `OMS_orderdata.csv` format.  
   - WMS Data: Download in `WMS_orderdata.csv` format.  

2. **Save Files**  
   - Place both files in the **`targetfolder`** directory.  

3. **Access Macro File**  
   - Open the **`order-not-flow-demo.xlsm`** folder.  

4. **Run Macro**  
   - Execute the process by clicking the **Run** button.  

5. **Save As**
   - Rename and Save As for **Result File**
   
7. **Confirmation**  
   - Click **OK** to complete the operation.
